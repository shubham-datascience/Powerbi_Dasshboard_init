E-Commerce Product Performance Dashboard (Power BI)
This Power BI project analyzes product performance across multiple e-commerce platforms using data from a product master file, daily transactional logs, and sales records. The dashboard provides dynamic and interactive insights into sales trends, platform performance, and product-level KPIs to support business decision-making.

🗂 Dataset Overview
Master File: Contains detailed product information including platform listings, brand, category, pricing, and attributes.

Sellout File: Records daily sales transactions including product IDs, quantities sold, total revenue, and customer/order metrics.

Sales File: Additional sales data for further cross-verification and reporting.

📌 Key Features
KPI Cards for:

Total Revenue

Total Quantity Sold

Average Order Value (AOV)

Number of Customers

Top 5 Products and Brands by revenue and quantity sold

Platform-wise Revenue Breakdown

Time Intelligence: Sales trends over time (monthly/weekly views)

"Sold vs. Not Sold" Product Segmentation

Interactive Slicers for:

Platform

Brand

Date

Category

Dynamic Charts:

Bar and Column charts for comparison

Line charts for trend analysis

Matrix visual for cross-dimensional views

🛠 Tools & Technologies
Power BI Desktop

DAX for measures and calculated columns

Power Query for data cleaning and transformation

Data modeling with relationships across multiple tables
